# Flat Repero web asset package

These are candidate distribution assets only. They do not replace the historical production icon in `public/brand/` or alter site code.

| Use | Asset |
| --- | --- |
| Light website background | `repero-mark-flat-transparent.svg` / `.png` |
| Dark website background | `repero-mark-flat-inverted-transparent.svg` / `.png` |
| Browser favicon | `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png` |
| Apple touch icon | `apple-touch-icon-180x180.png` |
| PWA icon | `pwa-icon-192x192.png`, `pwa-icon-512x512.png` |
| Maskable PWA icon | `pwa-icon-maskable-512x512.png` |
| Notification badge | `notification-badge-96x96.png` |

Transparent marks retain the flat R geometry and cyan locator dot. Favicon and PWA files use the night-blue, inverted mark so they remain visible on browser and operating-system surfaces.
