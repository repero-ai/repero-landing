# Repero website brand audit

## Deployed baseline

The current website source is `brand/logo/flat/web/`, deployed unchanged from `public/brand/flat-web/`.

- Dark header and footer surfaces use the inverted transparent flat SVG.
- Structured data uses the transparent flat SVG.
- Browser icons use the flat-web favicon and Apple touch derivatives.
- The standalone social fallback is `public/social/repero-ai-social-preview.png`, a 1200 × 630 composition using the approved white/cyan wordmark.

No web manifest is emitted: this marketing site is not a PWA. Historical icon and experimental brand sources are retained only outside the public deployment path.
