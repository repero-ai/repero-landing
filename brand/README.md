# Repero brand

## Current website source

`logo/flat/web/` is the current deployed website package. Its reviewed SVG and favicon derivatives are copied to `public/brand/flat-web/` without regeneration.

The website uses the inverted transparent flat mark on dark surfaces, the transparent flat mark for structured-data logos, and the white/cyan wordmark only in the separate social preview. Historical original and exploratory source files remain references, not deployed assets.
